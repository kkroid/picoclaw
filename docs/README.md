# OneAppFactory Documentation

This directory contains documentation for the current OneAppFactory product surface.

## Runtime Docs

- [configuration.md](configuration.md): config file shape, defaults, and environment variables.
- [providers.md](providers.md): model provider entries used by planning and builder runtime.
- [docker.md](docker.md): launcher and builder Docker setup.
- [debug.md](debug.md): where to inspect logs and job artifacts.
- [troubleshooting.md](troubleshooting.md): known AppFactory failure signatures and fixes.

## Design Docs

The active design material lives in [design](design). It includes the AppFactory extraction plan, runtime rule inventory, generic complexity roadmap, JSON schemas, and template registry.

Older docs for legacy non-AppFactory surfaces have been removed because those surfaces are no longer part of OneAppFactory.
