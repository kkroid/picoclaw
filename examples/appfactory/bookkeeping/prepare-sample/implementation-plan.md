# 实施计划

- Job ID: job-bookkeeping-prepare-sample
- PRD ID: prd-bookkeeping-prepare-sample

## 阶段拆分

- 阶段 1：冻结记账 App 最小范围，确认账单实体、收支汇总与概览/动作/集合三类承载关系。
- 阶段 2：把范围拆成 task bundle，生成 Builder 可执行的 acceptance checks。
- 阶段 3：通过当前 P0 adapter 写入交接探针并跑通最小链路，为后续接入真实 Flutter Builder runtime 留接口。

## 任务包

### 冻结账单实体与收支汇总模型

- 目标：先明确记账 App 的账单实体、派生汇总和目录落点，避免后续承载单元与存储边界反复漂移。
- 分类：domain
- 关联需求：feature-local-data, feature-home-summary
- 目标路径：lib/models/entry.dart, lib/models/summary.dart
- 预期输出：账单实体字段稳定；月度汇总可从账单实体推导
- 完成标准：账单记录包含金额、分类、日期和备注；汇总模型可以表达收入、支出和结余
- 风险提示：如果实体字段频繁变化，后续承载单元和测试都会跟着返工

### 接通本地持久化与账单仓储边界

- 目标：把本地持久化方案和 repository 边界固定下来，确保新增账单后可恢复概览与账单集合。
- 分类：storage
- 关联需求：feature-local-data
- 依赖任务：task-domain-models
- 目标路径：lib/repositories/entry_repository.dart, pubspec.yaml
- 预期输出：明确的本地持久化实现；账单读写入口稳定
- 完成标准：代码或依赖中出现明确的本地持久化实现；应用重启后仍能读取账单集合并恢复概览
- 风险提示：不要同时引入两个同类本地存储方案

### 绑定概览、记账动作与集合浏览承载单元

- 目标：先把概览承载、实体变更承载、集合浏览承载和主导航入口搭出来，不把默认 seed 骨架当作完成结果。
- 分类：screen
- 关联需求：feature-home-summary, feature-add-entry, feature-ledger
- 依赖任务：task-domain-models
- 目标路径：lib/main.dart, lib/views/home_page.dart, lib/views/entry_form_page.dart, lib/views/entry_list_page.dart
- 预期输出：概览承载单元骨架；记账动作承载单元骨架；账单集合浏览承载单元骨架
- 完成标准：概览、记账动作、账单集合浏览之间入口明确可达；默认 counter demo 页面与文案已被移除
- 风险提示：承载单元骨架完成不等于记账主流程闭环已接通

### 接通记账动作、概览刷新与账单集合回显主流程

- 目标：把账单录入保存、概览刷新和账单集合回显串成一个完整功能闭环。
- 分类：flow
- 关联需求：feature-add-entry, feature-home-summary, feature-ledger, feature-local-data
- 依赖任务：task-storage-wiring, task-bind-core-surfaces
- 目标路径：lib/controllers/home_controller.dart, lib/controllers/entry_form_controller.dart, lib/controllers/entry_list_controller.dart, lib/repositories/entry_repository.dart, test/widget_test.dart
- 预期输出：保存动作可触发持久化；概览和账单集合能看到新增账单
- 完成标准：记账动作字段齐全并可保存；新增账单后概览与账单集合都能反映最新数据
- 风险提示：不要为了接线方便重做整套承载结构或状态管理

### 完成 analyze、test 与 APK 构建收口

- 目标：在功能闭环接通后，通过低风险修复把工作区收敛到 analyze、test 和 debug APK 全通过。
- 分类：validation
- 关联需求：ac-entry, ac-ledger, ac-persistence, ac-navigation
- 依赖任务：task-flow-wiring
- 目标路径：lib/main.dart, lib/views/**, lib/controllers/**, lib/repositories/**, test/**, pubspec.yaml
- 预期输出：静态检查通过；测试通过；可构建 Debug APK
- 完成标准：flutter analyze 无错误；flutter test 全通过；flutter build apk --debug 成功
- 风险提示：只做低风险收口，不把单点失败扩展为大面积自由重构
